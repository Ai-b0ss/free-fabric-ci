1. `AGENTS.md`

If the task explicitly requires account-wide archaeology and authenticated GitHub access exposes additional private repositories, search those sources too. Keep private names, metadata, code, issue/PR contents and relationships out of public commits unless the owner explicitly chooses to publish them.

## Absence rule

“Not present in this public repo” means only that. It does not prove the owner never implemented or researched the idea elsewhere.
