# Gemini repository bootstrap

Read `AGENTS.md` before substantial repository work. It is the canonical agent contract.

Required navigation:
1. `docs/AGENT_OPERATING_SYSTEM.md`
2. `docs/AGENT_NAVIGATION.md`
3. task-specific state/tests/runbooks named there.

For forgotten or historical work, search all branch tips and reachable history with `tools/agent_history.py`. For exact code locations on any ref use `python tools/build_agent_index.py --ref "<branch-or-SHA>"`.

Do not replace existing work until repository history has been checked when the task suggests prior work may exist.
